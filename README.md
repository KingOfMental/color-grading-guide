# 영상제작 통합 학습서

기존 `color-grading-guide` 주소에서 촬영·라이팅, 색채·DaVinci Resolve, Final Cut Pro 편집·사운드·왕복 작업을 한 목차와 검색으로 읽는 한국어 학습자료입니다.

## 학습 순서

1. 빛·눈·명암 → 색의 속성·대비·배색
2. 샷·구도·화면 방향 → 기록·노출·라이팅 → 짐벌 경로·초점
3. 파일·프로젝트·FPS·입력/출력 약속 → 원본·프록시·최적화
4. 선별·기본 컷·트림 → 장면·전체 흐름
5. 음악 구조·역할·레벨 → 속도 변화
6. 보기 조건·색관리 → 노드·스코프 → 기본 보정·부분 보정·샷 매칭
7. 룩·질감·합성·전환·작품 사례
8. 왕복 계약·XML·반환·수정 → 출력·검수·보관

전체 단원의 선행 개념을 점검해 재배치했습니다. 사이트 첫 화면의 ‘전체 학습 순서를 이렇게 바꿨어요’에서 변경 이유를 확인할 수 있습니다.

## 목차와 영화 사례

대분류는 색채학 / 촬영 / 파이널컷(컷편집) / 다빈치리졸브(색보정) / 기타, 정확히 5개입니다. 그 아래 중분류 → 주제 → 개별 설명을 둡니다. 현재 읽는 주제만 자동으로 펼쳐지고, 각 주제는 최대 10항목입니다. 전체 368항목과 기존 링크·이미지·비교 기능은 보존했습니다.

블랙스완 영화 사례는 핵심 11편과 비교·보조 2편을 합쳐 13편입니다. 첫 화면의 영화 사례 링크 또는 룩 단원의 영화 사례 묶음에서 찾습니다. 공개 설명 자막을 출발점으로 작품별 학습 설명을 새로 작성했고, 해석·직접 확인한 이미지·교재 적용을 구분했습니다. 어톤먼트 공식 홍보 콜라주는 별도 관찰과 출처를 표시했습니다. 전체 영화 연속 시청이나 미확인 프레임 관찰을 완료했다고 표시하지 않습니다.

## 보존·보강 범위

- 기존 색채 본문 214쪽, 장면 사진 5개와 전후 비교
- 기존 Final Cut Pro 웹 교재 83항목의 본문·그림·이미지·조작 실험
- Ejim·BLVCKSWAN 검토를 연결한 원리 보강 33항목
- 촬영·짐벌·편집에서 배울 원리를 독립적으로 구성한 교육 설명 15항목
- 모든 항목을 함께 찾는 검색, 단원 필터, 선행 개념에 맞춘 이전/다음 이동

유료 강의의 장면·자막·시간대·개별 링크를 옮기지 않고, 배울 원리를 새 설명과 자체 예시로 재구성했습니다.

예전 `#page-숫자` 주소는 색채 원본 쪽번호로 유지됩니다. 새 목차와 이전/다음 이동은 통합 순서를 따릅니다. 오래된 세부 목차·사전은 마지막 단원에 보존했습니다.

## 확인 수준


원본 유료 강의 영상·전체 자막·계정 정보·비공개 부속 파일은 포함하지 않습니다. 기존 공개 파이널컷 교재의 이미지는 동일 파일로 재사용하고, 새 설명은 독자적으로 정리했습니다. 기술 용어와 버전·기종 조건은 공식 안내를 연결합니다.

## 수정과 검증

- `content/supplements.json`: 색채·촬영·라이팅·사운드 보강
- `tools/build_unified.py`: 두 기존 웹 교재와 보강 내용을 통합
- `docs/assets/unified.js`, `unified.css`: 통합 탐색·본문·배치
- `tools/validate_unified.py`: 내용 보존·이미지·링크·학습 선후관계 검증

```sh
python tools/build_unified.py
python tools/validate_unified.py
```

빌드 스크립트는 Python과 lxml을 사용합니다. 배포 결과는 의존성 없는 정적 HTML/JS입니다. `content/`의 원본 교재 스냅샷과 `docs/assets/`의 기존 이미지를 보존하므로 웹 배포에 PDF를 올릴 필요가 없습니다.
