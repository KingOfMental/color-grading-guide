# 색채학 · 색보정 · DaVinci Resolve 학습 사전

색채학부터 작업 절차, DaVinci Resolve, 필름 룩까지 연결하는 한국어 학습자료입니다.

- 214쪽 본문과 전체 텍스트 검색, 목차, 페이지 이동
- 62개 전후 비교 항목과 95개 변형: 드래그 바, 키보드, 비교 위치 버튼
- 실제 영화 스틸·공식 홍보사진 5개와 출처·관찰 가이드
- 필요한 이미지부터 불러오는 정적 웹사이트

## GitHub Pages에서 보기

1. 이 폴더의 내용을 저장소의 `main` 브랜치에 올립니다. `.github` 폴더도 포함합니다.
2. 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
3. **Actions → Publish learning guide → Run workflow**를 실행합니다.
4. 배포가 성공하면 **Settings → Pages**에 표시되는 사이트 주소로 접속합니다.

이후 `docs/`의 변경을 `main`에 올리면 자동으로 다시 배포됩니다. 방문자는 같은 주소를 새로고침하면 보충된 자료를 볼 수 있습니다. 변경 저장부터 배포 완료까지 시간이 걸릴 수 있습니다.

## 로컬 확인

```sh
python3 -m http.server 8000 --directory docs
```

브라우저에서 `http://localhost:8000`을 엽니다. 별도의 빌드나 npm 설치가 필요하지 않습니다.

## 수정 위치

- `docs/index.html`: 본문 검색 데이터, 비교 예시 설명, 장면 가이드
- `docs/assets/site.css`: 화면 배치와 스타일
- `docs/assets/app.js`: 검색·탐색·비교 동작
- `docs/assets/images/`: 본문과 예시 이미지

본문 페이지는 책의 페이지 이미지와 검색용 텍스트로 구성됩니다. 책 본문을 바꿀 때는 해당 페이지 이미지와 검색용 텍스트를 함께 수정해야 합니다. 새 비교 사례의 이미지는 같은 촬영본을 기준으로 맞춰야 합니다.

## 자료의 범위와 출처

예시 변형은 원리를 설명하기 위한 교육용 처리이며 Resolve FX의 실제 출력이나 작품의 제작 노드·LUT를 재현했다는 뜻이 아닙니다. 영화 가이드는 공개 인터뷰·자료를 근거로 한 관찰과 실습 제안입니다. 사진별 출처와 스틸/홍보사진 구분은 본문에 표시합니다. 원래 제공된 YouTube 링크는 참고 목록이며 전체 영상·자막을 분석했다는 뜻이 아닙니다.

외부 사진과 인용 자료의 권리는 원저작자에게 있습니다. 저장소에 일괄적인 오픈 소스 라이선스를 부여하지 않습니다.
